# Uncertainty_Project_depletion_q

This folder contains the current depletion_q uncertainty workflow for the Little Plover River PyCap analysis.

## Purpose

The workflow asks:

> If pumping decisions are optimized under an assumed aquifer parameter set, how do those decisions perform when transmissivity (T) and storage (S) are uncertain?

The current workflow focuses on the `depletion_q` objective so the tradeoff is directly tied to total pumping and Little Plover River streamflow/depletion.

## Notebook order

Run notebooks in this order:

1. `300_validate_depletion_q_baseline_reevaluation.ipynb`
   - Validates that the fixed-design re-evaluation reproduces the original depletion_q baseline Pareto results.

2. `301a_individual_parameter_known_error_depletion_q.ipynb`
   - Evaluates individual known-error scenarios for transmissivity and storage.
   - Supports `PARAMETER_TO_RUN = "transmissivity"` and `PARAMETER_TO_RUN = "storage"`.

3. `301b_combined_T_storage_known_error_depletion_q.ipynb`
   - Evaluates combined T/S known-error scenarios.
   - Compares combined effects against additive expectations from the 301a T-only and S-only runs.

4. `302a_probability_weighted_individual_parameter_uncertainty_depletion_q.ipynb`
   - Evaluates individual probability-weighted uncertainty for transmissivity and storage.

5. `302b_joint_T_storage_probability_weighted_uncertainty_depletion_q.ipynb`
   - Evaluates joint T/S probability-weighted uncertainty using a 5x5 grid.

6. `303_uncertainty_report_figures_depletion_q.ipynb`
   - Collects synthesis figures and report-ready tables.

7. `304_robust_decision_analysis_depletion_q.ipynb`
   - Converts uncertainty results into robust-decision metrics such as streamflow shortfall, reliability, and robust pumping limits.

## Key folders

- `cached_reevaluations/`
  - Cached long-format re-evaluation results.
  - These files allow most notebooks to be rerun with `RERUN_REEVALUATION = False`.

- `project_output/`
  - Tables, figures, and Markdown summaries generated by the notebooks.

## Important helper file

The notebooks require:

```text
uncertainty_project_helpers_depletion_q.py
```

Do not delete this file. It contains the PyCap re-evaluation functions, plotting utilities, probability summaries, and path helpers used across the workflow.

## Recommended rerun approach

For expensive notebooks, use:

```python
RERUN_REEVALUATION = False
N_TEST_MEMBERS = None
```

after the cached results already exist.

Use:

```python
RERUN_REEVALUATION = True
N_TEST_MEMBERS = 10
```

for a short test run before rebuilding a full cache.
